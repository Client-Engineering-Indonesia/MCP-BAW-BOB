## Overview

Workflow automation improves productivity and streamlines daily business operations through:

- **Authoring environment** - Create and configure workflow automations
- **Frameworks/models** - Sequence and delegate work (structured processes or unstructured cases)
- **User experience** - Interact with applications through standardized workflows
- **Administrative tools** - Optimize performance, deploy versions, and manage security

## Project Types

- **Workflow Automation** - Contains process and case definitions, artifacts, and asset types
- **Template** - Predefined starting points for creating case solutions
- **Toolkit** - Shared artifacts used across multiple workflow automations

## Work Portals

- **Workplace** - Modern, customizable interface for tasks, workflows, and cases
- **Process Portal** - Earlier coach-based interface for tasks and process instances
